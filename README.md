# 中文学习与收藏

个人公开学习笔记与资料整理区。仅收录可以公开分享的内容。

## 目录

- [学习记录模板](templates/学习记录.md)：记录目标、操作、结果与后续问题。
- [资料收藏模板](templates/资料收藏.md)：记录来源、用途及查阅情况。
- [笔记索引](notes/README.md)：后续学习记录的入口。

## 使用方式

复制模板到 `notes/日期-主题.md`，填写实际学习内容，然后把链接加入笔记索引。模板中的空白项不是已经完成的学习记录。

公共资源链接集中维护在 [中文资源精选合集](https://github.com/zhifanfang86-gif/awesome-chinese-resources)，本仓库侧重个人理解、操作记录和复盘。

本仓库公开：不记录账号密码、API Key、个人隐私及公司内部信息。
